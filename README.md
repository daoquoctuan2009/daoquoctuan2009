## Featured project

### [Fuzzy Search for Motorcycle Parts](https://github.com/daoquoctuan2009/fuzzy-search-for-motorcycle-part)

A Python prototype for matching customer descriptions to catalog products when spelling, Vietnamese accents, abbreviations, and product details vary.

The implementation combines:

- **N-gram indexes and TF-IDF similarity** to retrieve and rank candidates.
- **Levenshtein edit distance and Jaccard overlap** to handle imperfect text matches.
- **Domain-specific rules** for motorcycle-part details such as size, position, and side.
- **A Flask interface and export code** for a workflow from batch queries to selected items.

**Technologies:** Python · pandas · Flask · RapidFuzz · Vietnamese text processing

[Read the project showcase](https://github.com/daoquoctuan2009/fuzzy-search-for-motorcycle-part) · [Explore the source](https://github.com/daoquoctuan2009/fuzzysearch_gemini_ptxm/tree/feat-run-locally)

The project is a prototype. The showcase documents its current limitations and proposed evaluation rather than claiming measured accuracy or production readiness.
